# Expense Tracker CLI

[![Go version](https://img.shields.io/github/go-mod/go-version/itsabyr/expense-tracker-cli)](go.mod)
[![License](https://img.shields.io/github/license/itsabyr/expense-tracker-cli)](LICENSE)

Консольное приложение «Учёт расходов» на Go, работающее с пользовательским вводом. Учебный проект для самостоятельного закрепления материала первой части [полного курса по Golang](https://www.youtube.com/watch?v=dpvRDJjUJf8).

> **Важно.** Цель проекта — повторение пройденного материала, а не демонстрация лучших практик. Многие подходящие для этой задачи инструменты и приёмы намеренно не используются.

## Возможности

### Расходы

- Добавление новых расходов
- Просмотр полного списка расходов
- Просмотр общей суммы расходов
- Удаление расхода по идентификатору
- Просмотр расходов по категории

Каждый расход содержит:

| Поле | Описание |
|------|----------|
| ID | Уникальный идентификатор расхода |
| Категория | Категория расхода |
| Сумма | Сумма расхода |
| Описание | Краткое описание расхода |
| Время создания | Фиксируется при добавлении |

Все расходы хранятся в памяти программы на протяжении её работы.

### События

Событием считается каждый пользовательский ввод. Для каждого события сохраняются:

- текст пользовательского ввода;
- описание: текст ошибки, если ввод завершился ошибкой, иначе пустая строка;
- время создания события.

Список всех событий за время работы программы доступен через команду `events`.

## Команды

| Команда | Формат | Описание |
|---------|--------|----------|
| `help` | `help` | Показать доступные команды и их формат |
| `add` | `add {категория} {сумма} {описание}` | Добавить расход |
| `list` | `list` | Вывести список всех расходов |
| `total` | `total` | Вывести общую сумму расходов |
| `category` | `category {название}` | Вывести расходы по указанной категории |
| `del` | `del {id}` | Удалить расход по идентификатору |
| `events` | `events` | Вывести список всех событий |
| `exit` | `exit` | Завершить работу программы |

### Пример использования

```text
> add food 1500 Купить продукты
> add transport 500 Поездка на такси
> list
> total
> category food
> del 1
> events
> exit
```

## Технические детали

- Оформлено как Go-модуль: `github.com/itsabyr/expense-tracker-cli`
- Помимо пакета `main`, может содержать дополнительные пакеты
- Сторонние библиотеки не требуются

## Запуск

Требуется установленный [Go](https://go.dev/dl/).

```bash
git clone https://github.com/itsabyr/expense-tracker-cli.git
cd expense-tracker-cli
go run .
```
